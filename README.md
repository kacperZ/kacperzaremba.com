# kacperzaremba.com

Personal business-card site, hosted on GitHub Pages at [kacperzaremba.com](https://kacperzaremba.com).

- `index.html` — the whole site (single file, no build step, no dependencies)
- `CNAME` — custom-domain binding for GitHub Pages

## Updating

Edit `index.html`, commit, and push to `main` — GitHub Pages redeploys automatically within a minute or two.
